# ROADMAP · 后续可能加的功能

记录一些值得考虑的改进方向，不是承诺一定会做。

## 短期（容易加）

### 📊 简单图表
- 最近 12 个月的储蓄率趋势图
- 各分类预算 vs 实际的对比柱状图
- 婚礼基金累计曲线
- 技术：用 SVG 手写，不引 Chart.js（保持零依赖）

### 💰 汇率历史
- 每月可以记录当月实际换汇汇率
- 分析时用历史汇率而不是固定的 0.87
- 年度查看汇率波动对总开销的影响

### 🎯 储蓄目标追踪
- 应急金进度（目标 ¥100,000 对半分）
- 婚礼基金进度（目标 HK$ 57,600）
- 独立的追踪页面，带可视化进度条

### ⚡ 快速填写优化
- 固定开销默认勾选"和上月相同"，一键填入上月实际
- Tab 键在输入框间顺序跳转
- 最近编辑的月份快速切换按钮

## 中期（需要设计）

### 📝 开销分析
- 月度对比：本月 vs 上月 vs 去年同月
- 分类占比饼图
- 标注"异常月份"（支出超出预算 20%+）

### 🎨 预算方案切换
- 激进版 / 标准版 / 保守版预算切换
- 婚礼前 / 婚礼后的预算切换
- 每月可选不同预算方案

### 🔔 提醒 / 洞察
- "本月餐饮已超支，还有 X 天"
- "这个月储蓄率高于平均，真棒"
- 婚礼基金达标提醒
- Web Notification API 实现

### 📱 PWA 化
- 加 manifest.json，可安装到手机桌面
- Service Worker 离线可用
- 加 app icon

## 长期（需要考虑架构）

### ☁️ 云同步（谨慎考虑）
- 用 Supabase / Firebase 免费层
- 多设备数据同步
- 需要考虑：账号、隐私、是否值得引入后端
- 当前的"导出 JSON + 云盘同步"已经足够用了

### 👥 双人账本
- 伴侣共同记账
- 需要账号系统
- 优先级低，除非结婚后真有这个需求

### 📤 对接记账 App
- 从随手记、MoneyWiz 等导入月度汇总
- 减少手动录入
- 技术难度：各 app 导出格式不同，需要适配层

## 不做（刻意排除）

- ❌ 每日记账：用户明确说用手机 app 记，本工具只做月度汇总
- ❌ 复杂的投资追踪：基金定投由银行/券商 app 管理
- ❌ 税务计算：太复杂，且用户是港币收入情况特殊
- ❌ 多用户：单人工具，保持简单
- ❌ 加密货币：用户不需要

## 优先级排序（个人偏好）

如果要按价值/成本来排：

1. 🌟🌟🌟 储蓄目标追踪页面（高价值，简单）
2. 🌟🌟🌟 快速填写优化（天天用，省时间）
3. 🌟🌟 简单图表（让数据更直观）
4. 🌟🌟 汇率历史（对跨境场景重要）
5. 🌟 PWA 化（锦上添花）

不要一次性做太多。一次改一个小功能，保持可维护性。
